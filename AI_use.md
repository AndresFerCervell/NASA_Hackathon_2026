## Document for recording AI use

AI used in this project: Chatgpt Codex and Google Antigravity. 

### Use in backend:

The produced code is generated with AI, guided by the ideas and decisions of the team members.

The datasets used and the calculation methodology are the team members' ideas. The code to implement these solutions is generated by AI and reviewed by the team members.

AI was used for translation.

### Use in frontend:

The code of the backend was generated with the help of Antigravity and other skills.
- Generated a preview of a 3D moon.
- Generated a simulation of Lunar, Earth and Sun orbits.
- Generated a User Interface using with design made by team members from figma sketch.
- Added skills to use AI. AI wrote what those skills are in the README.
